Architecture#

scrap is one Python process, one SQLite file and one folder of files. This page is the map; the pages under it go deep on each part.

Principles#

Principle

Meaning

Record

Tiny

One process, one database file, one folder of files. A feature that needs a second service waits.

0003

Off the shelf

Claude reads and writes, SQLite stores and searches, Tailscale routes, Excalidraw draws. scrap is the glue.

0003

Originals kept, the rest derived

Derived text can be regenerated (a saved link’s article is fetched to be read, not stored). The search index is disposable.

0004

Capture never waits

Saving is a file write and a few row inserts. Anything slow runs later.

0005

Claude reasons, the PWA shows

Claude (over MCP) is for asking and writing; the PWA is for capturing and looking.

0013

The whole system#

Everything runs in one process; the only things outside it are the disk and the internet.

  • The process also serves the built PWA as static files, mounted after the API and /mcp routes.

  • The worker thread starts from the FastAPI lifespan only when SCRAP_INGEST=on (the default is off). Capture, search and everything else work without it.

  • The API and the worker both write, so every connection sets PRAGMA foreign_keys = ON and PRAGMA busy_timeout = 5000 on open; the database is in WAL mode.

  • The CLI (scrap backup, restore, export, import, gc, enrich, ingest-once) opens the same data folder directly; scrap serve migrates, then serves.

  • No login code. Tailscale Serve is the way in; on Kubernetes a proxy fronts it, with an optional bearer token on /mcp (7. Tailscale Serve is the only way in; no login code, 23. Bearer token on /mcp and an identity-header setting).

Package

Role

store/

Pages, captures, blobs, tags, revisions, trash, search, health checks, schema and migrations.

ingest/

The job queue and its worker thread: photo ingest, refine, pause and resume.

enrich/

Claude’s reading of text pages: summary, tags, related pages, board write-ups, topic pages.

claude.py, claude_cli.py

The Messages API client and the Claude seat (claude -p) backend.

mcp_tools/

The tools served at /mcp.

importer/

Reads a Thoth vault and writes it through Store.

One capture becomes one page#

Each capture creates its own page at once; Claude’s work follows in the background.

        sequenceDiagram
    participant U as PWA
    participant S as store/
    participant W as Worker
    participant C as Anthropic API
    U->>S: POST /api/captures (ULID, text, files)
    S-->>U: 201, page created
    Note over S: blobs, capture, page, rev 1, job queued
    W->>S: claim next job
    W->>C: one structured call per photo
    C-->>W: text, title, tags, summary
    W->>S: write derived rows, update page, reindex

Every capture kind (note, link, photo, file) gets its own page; what goes in the body and title is tabled on Capture, files and import.

Ingest is a fixed pipeline with no search-then-decide loop. Merging and cross-linking pages is done by hand or through MCP write. Details are in Capture, files and import and Job queue and Claude features.

Deferred#

  • Voice memos (needs a transcriber) and Background Sync for the upload queue.

  • Filing captures into existing pages, and automatic cross-linking.

  • A namespace column for read scoping by less trusted surfaces.

  • Embeddings and hybrid search, if exact words stop being enough (8. Search is SQLite FTS5 with a shared query syntax; embeddings are deferred).

  • An empty-trash command: pages leave the trash only by the nightly purge, N days on (30. The trash is purged after N days).

  • A page listing dead jobs; queue state shows on each page and in GET /api/ingest.

  • Chat and refine on a photo’s stored model run.

  • Larger ideas: a work browser route behind Cloudflare Access, a work sandbox over MCP only, a remote Claude Code session with only the scrap MCP server, a separate ingest worker.

Open questions#

  • Headless terms. claude setup-token is Claude Code’s route for headless use and the seat backend uses it (ADR 0021). Whether an organisation allows a seat to run unattended is its own policy.

  • Audio transcription. Local faster-whisper or a hosted API.

  • Postgres and pgvector, only if SQLite is outgrown.

  • Tailscale Kubernetes operator. Whether its ingress passes identity headers through; its source says it does, not yet verified (Deploy on Kubernetes).
