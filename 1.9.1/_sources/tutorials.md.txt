# Tutorials

Tutorials for installing scrap. New users start here: pick the one that matches where you want
to run it.

- **Try it on your LAN**: one container, no login, the quickest try.
- **One server with Tailscale**: systemd and rootless podman on a VPS or home server.
- **Kubernetes with Cloudflare**: the Helm chart, with Litestream, behind Cloudflare Access.
- **At DLS**: one script on the argus cluster; start here if you work at Diamond.
- **Ingest on a Claude seat**: added to any of them, to read photos with a Claude subscription.
